## Propósito

Materializar el ADN de la Super Plantilla Maestra Canónica v3.0 en un vault Obsidian + Agent Skills que permita:

- Captura, clasificación, análisis y ejecución de conocimiento bajo los 7 NPCs.
- Compartimentación estricta Dominio A / Dominio B.
- Dashboard ICP y health-check.
- Integración con el Segundo Cerebro Positrónico y con GitHub Copilot (actual y futura).
- Trazabilidad completa y soberanía mínima.
